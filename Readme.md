# 🚀 Commit Craft (Git Semantic Committer)

A simple interactive command-line interface designed to streamline git commit messages following standard Conventional Commit guidelines.

---

## ✨ Features
- **Interactive Prompts:** Guides you through selecting commit types (`feat`, `fix`, `docs`, `refactor`, etc.).
- **Scope & Description:** Easily add component scopes and breaking change warnings.
- **Git Hook Ready:** Can be executed via terminal command or integrated directly into pre-commit hooks.

---

## 🛠️ Tech Stack
- **Runtime:** Node.js / Bash
- **Target:** Git integration CLI tool

---

## 🏃 Quick Start

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/SenaEnana/commit-craft.git](https://github.com/SenaEnana/commit-craft.git)
   cd commit-craft
   ```
2. **Run locally:**
   ```bash
   npm start
   ```
